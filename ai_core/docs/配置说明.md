# AI 饮食助手 — 配置说明

## 目录结构

```
AI_Diet_Assistant/
├── ai_core/                    ← Python 后端（AI 引擎）
│   ├── main.py                 ← 主入口
│   ├── models/
│   │   ├── cloudmodel_import.py  ← 云端模型（DeepSeek）调用
│   │   └── ollama_import.py      ← 本地模型（Ollama）调用
│   ├── logs/                   ← 运行日志目录（自动创建）
│   ├── docs/                   ← 文档目录
│   └── test/                   ← 测试参数
├── server/                       ← C++ 后端（Web 服务器）
│   ├── backend.cpp             ← 主程序
│   ├── Config.json             ← JSON 格式完整配置
│   ├── config.txt              ← 简化的键值对配置（backend 启动参数）
│   ├── frontend/               ← 前端静态页面
│   └── CMakeLists.txt          ← 构建文件
└── weather_district_id.csv     ← 百度天气地区代码表
```

## 一、C++ 后端配置

### 1.1 简化配置 `server/config.txt`

| 键 | 说明 | 示例值 |
|---|---|---|
| `port` | 服务器监听的端口 | `8080` |
| `static_dir` | 前端静态文件目录（相对于 server/） | `./frontend` |
| `python_script` | Python 后端脚本路径（相对于 server/） | `../ai_core/main.py` |
| `primary_model` | 一级模型供应商 | `ollama` |
| `primary_model_name` | 一级模型名称 | `deepseek-r1:7b` |
| `secondary_model` | 二级模型供应商 | `deepseek` |
| `secondary_model_name` | 二级模型名称 | `deepseek-chat` |
| `ollama_server` | Ollama 服务地址 | `http://localhost:11434` |

> **说明**：C++ 启动时读取此文件，组装成 `--primary_model_id` 和 `--secondary_model_id` 传给 Python 脚本。
> 格式为 `{primary_model}:{primary_model_name}`，例如 `ollama:deepseek-r1:7b`。

---

### 1.2 完整配置 `server/Config.json`

一个 JSON 对象，存储更详细的配置，C++ 端也在运行时读取。

#### `server` — 服务器配置

```json
{
    "port": 8080,
    "static_dir": "./frontend"
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `port` | int | HTTP 监听端口 |
| `static_dir` | string | 静态文件根目录 |

#### `weather_api` — 天气 API 配置（百度天气）

```json
{
    "ak": "",
    "base_url": "https://api.map.baidu.com/weather/v1/",
    "district_id": "510100",
    "city_name": "成都市",
    "location": "成都市",
    "cached_weather": { ... }
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `ak` | string | **百度地图 API Key**（必须填写才可获取实时天气） |
| `base_url` | string | 百度天气 API 基础地址 |
| `district_id` | string | 地区编码（见 `weather_district_id.csv`） |
| `city_name` | string | 城市名 |
| `location` | string | 位置描述 |
| `cached_weather` | object | 天气缓存（包含 now / forecasts / indexes / alerts） |

`cached_weather` 结构：

| 子字段 | 类型 | 说明 |
|---|---|---|
| `now` | object | 当前天气（temperature、feels_like、condition、wind_dir 等） |
| `forecasts` | array | 未来天气预报（7天左右） |
| `indexes` | array | 生活指数（晨练、洗车、感冒、穿衣、运动等） |
| `alerts` | array | 天气预警 |

> **注意**：运行时若 `ak` 为空或请求失败，会使用 `cached_weather` 中的缓存数据。

#### `models` — AI 模型配置

```json
{
    "primary": {
        "type": "ollama",
        "model": "gpt-oss:120b-cloud",
        "api_key": ""
    },
    "secondary": {
        "type": "deepseek",
        "model": "deepseek-chat",
        "api_key": "",
        "ollama_server": "http://localhost:11434",
        "enabled": true
    }
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `primary.type` | string | 一级模型供应商标识（如 `ollama`） |
| `primary.model` | string | 一级模型名称（与 `config.txt` 中 `primary_model_name` 含义相同） |
| `primary.api_key` | string | 一级模型的 API Key（Ollama 本地模型一般无需） |
| `secondary.type` | string | 二级模型供应商标识（如 `deepseek`） |
| `secondary.model` | string | 二级模型名称 |
| `secondary.api_key` | string | **二级模型的 API Key**（云端模型必须填写） |
| `secondary.ollama_server` | string | Ollama 服务地址（二级为 deepseek 时可通过此配置代理） |
| `secondary.enabled` | bool | 是否启用二级模型（对应 `--use_secondary` 参数） |

#### `user_profile` — 用户默认档案

```json
{
    "age": "25",
    "gender": "男",
    "height": "170",
    "weight": "52",
    "occupation": "学生",
    "taste": "",
    "health": ""
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `age` | string | 年龄 |
| `gender` | string | 性别（男/女） |
| `height` | string | 身高（cm） |
| `weight` | string | 体重（kg） |
| `occupation` | string | 职业 |
| `taste` | string | 口味偏好（可选，如"清淡"、"辛辣"） |
| `health` | string | 健康状况备注（可选，如"胃炎"、"糖尿病"） |

> **说明**：前端页面会读取此默认档案填充表单，用户可自行修改后提交。

## 二、Python 后端配置

所有的 Python 配置都通过**命令行参数**传入（由 C++ 后端或手动调用时传入）。

### 2.1 命令行参数表

| 参数 | 类型 | 必需 | 说明 |
|---|---|---|---|
| `--request_file` | string | 否 | 请求 JSON 文件路径（与下面各项互斥，指定后从文件读取所有参数） |
| `--user_input` | string | **是** | 用户对话框输入 |
| `--personal_info` | string | 否 | 用户个人信息（JSON 或纯文本），如 `'{"age":25,"gender":"男"}'` |
| `--weather` | string | 否 | 天气数据（JSON 或纯文本） |
| `--primary_model_id` | string | **是** | 一级模型 ID，格式 `provider:model_name`，如 `ollama:deepseek-r1:7b` |
| `--secondary_model_id` | string | 否 | 二级模型 ID，格式同上，如 `deepseek:deepseek-chat` |
| `--use_secondary` | flag | 否 | 加此参数才调用二级模型进行推荐，否则仅返回一级预处理结果 |

### 2.2 通过 request_file 传入

当 `--request_file` 指定时，从 JSON 文件读取参数。文件内容示例：

```json
{
    "user_input": "今天推荐吃什么",
    "personal_info": "{\"age\":\"25\",\"gender\":\"男\",\"height\":\"170\",\"weight\":\"52\"}",
    "weather": "{\"now\":{\"temperature\":20,\"condition\":\"多云\"}}",
    "primary_model_id": "ollama:deepseek-r1:7b",
    "secondary_model_id": "deepseek:deepseek-chat",
    "use_secondary": true,
    "conversation_id": "conv_001",
    "conversation_title": "午餐推荐",
    "conversation_context": ""
}
```

> **说明**：`request_file` 中的字段优先级高于命令行对应参数，`conversation_*` 字段仅通过 `request_file` 传入（无命令行对应项）。

### 2.3 日志位置

| 文件 | 路径 | 说明 |
|---|---|---|
| `service.log` | `ai_core/logs/service.log` | 程序运行日志（INFO 及以上级别） |
| `{日期}.jsonl` | `ai_core/logs/2026-04-27.jsonl` | 每次请求的详细记录（JSONL 格式），包含输入、输出、耗时等 |

## 三、环境变量

| 变量 | 说明 | 取值位置 |
|---|---|---|
| `DEEPSEEK_API_KEY` | DeepSeek 模型 API Key | `cloudmodel_import.py` 读取 |
| `OLLAMA_API_KEY` | Ollama 服务的 API Key（如果需要） | `ollama_import.py` 读取 |

> **注意**：环境变量在运行 Python 脚本的终端中设置。
