# 使用说明

## 启动项目

双击**启动项目.exe**启动项目，启动后会在终端运行，浏览器会打开网页。
浏览器监听端口为：8080

启动后会获取ollama的配置信息，可以在左侧快捷设置模型和天气api。

## 天气AK配置

https://lbsyun.baidu.com/

访问该链接获取百度天气api调用权限。

（api调用需要配置个人公网ip）

### 公网ip查询

[iP地址查询--手机号码查询归属地 | 邮政编码查询 | iP地址归属地查询 | 身份证号码验证在线查询网](https://ip138.com/)

点击该链接查询当前使用的公网IP以完成百度API调用的白名单配置。



## 模型配置

### Ollama配置

[Ollama](https://ollama.com/)

ollama下载链接，下载对应版本ollama后可选择模型下载或调用云端模型。

ollama服务地址配置：http://localhost:11434

### deepseekAPI配置

https://platform.deepseek.com/

deepseek开放平台链接，可通过该平台获取api-key
