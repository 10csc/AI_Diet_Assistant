# AI_Diet_Assistant 环境配置与依赖说明

## 项目简介

AI_Demo 目录是项目的 Python 后端，负责：
- 通过命令行接收用户输入的个人信息、天气状况和饮食需求
- 调用本地 Ollama 服务进行输入预处理（隐私脱敏）
- 调用云端 DeepSeek API 生成饮食推荐
- 输出结构化的饮食建议（菜名、食材、烹饪方式、营养、推荐理由）

---

## 运行环境

### Python 版本

- **Python 3.12+** （开发环境使用 Python 3.12.6）
- 可从 https://www.python.org/downloads/ 下载安装

### Python 依赖

当前项目分为两部分依赖：

- 标准库依赖
- RAG 向量检索依赖

标准库模块如下：

| 模块 | 用途 |
|------|------|
| `argparse` | 命令行参数解析 |
| `json` | JSON 数据序列化/反序列化 |
| `sys` | 系统退出码等 |
| `os` | 环境变量读取（API Key） |
| `time` | 接口调用计时 |
| `logging` | 日志记录 |
| `datetime` | 日期时间处理 |
| `typing` | 类型注解 |
| `re` | 正则表达式（从响应中提取 JSON） |
| `urllib.request` | HTTP 请求调用 API |
| `urllib.error` | HTTP 请求异常处理 |

RAG 向量检索新增第三方依赖：

| 包名 | 用途 |
|------|------|
| `chromadb` | 本地持久化向量数据库，用于“用户所需营养 -> 食材候选”的中间层检索 |
| `sentence-transformers` | 中文语义向量模型加载与推理，用于生成食材文档和营养需求查询向量 |

安装方式：

```bash
cd f:\CodeFile\AI_Diet_Assistant\AI_Demo
python -m pip install -r requirements.txt
```

首次运行说明：

- 中文语义向量默认模型为 `BAAI/bge-small-zh-v1.5`
- 首次运行时会自动下载模型，请保持网络可用
- 若下载失败，系统会自动回退到本地哈希向量，保证项目仍可运行

## 外部服务依赖

虽然项目大部分逻辑仍以本地代码为主，但程序运行依赖于以下组件或外部服务：

| 服务 | 必需？ | 说明 |
|------|--------|------|
| **ChromaDB** | 是（RAG 食材检索阶段） | 本地持久化向量数据库，负责中间层“营养需求 -> 食材候选”检索 |
| **Ollama** | 是（预处理阶段） | 本地运行的大模型服务，默认地址 `http://localhost:11434`，需预先安装并拉取模型（如 `deepseek-r1:7b`） |
| **DeepSeek API** | 是（推荐生成阶段） | 云端 API，需在环境变量 `DEEPSEEK_API_KEY` 中设置 API Key |

### Ollama 安装参考

1. 从 https://ollama.com/download 下载安装
2. 拉取所需模型：`ollama pull deepseek-r1:7b`
3. 确保服务运行中：`ollama serve`

## 启动方式

```bash
cd f:\CodeFile\AI_Diet_Assistant
python AI_Demo/main.py \
  --user_input "我今天有点感冒，想吃点清淡的" \
  --personal_info '{"age": 25, "gender": "男", "allergies": ["海鲜"]}' \
  --weather '{"temp": 10, "condition": "阴雨"}' \
  --primary_model_id "ollama:deepseek-r1:7b"
```

参数说明：
- `--user_input`：用户饮食需求（必需）
- `--personal_info`：用户个人信息 JSON（可选）
- `--weather`：天气信息 JSON（可选）
- `--primary_model_id`：预处理模型 ID，固定格式 `ollama:模型名`（可选，默认 `ollama:deepseek-r1:7b`）

## 环境变量

| 变量名 | 说明 | 示例值 |
|--------|------|--------|
| `DEEPSEEK_API_KEY` | DeepSeek API 密钥（必需） | `sk-xxxxxxxxxxxxxxxx` |

可在命令行设置：
```cmd
set DEEPSEEK_API_KEY=sk-your-key-here
```

或者在 `cloudmodel_import.py` 中直接配置（不推荐）。
